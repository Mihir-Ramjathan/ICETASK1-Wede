# CSS Selectors and Pseudo-Classes ICE Task

## Project Description

This project demonstrates the use of different CSS selectors and pseudo-classes. The webpage is for a fictional academy called **CodeSpace Academy**.

The HTML was provided for the task, and an external CSS file called `style.css` was created to style the webpage.

## Files

* `index.html` – Contains the HTML structure of the webpage.
* `style.css` – Contains all the CSS styling and selectors.

## CSS Selectors Used

The following CSS selectors were used in the project:

### Element Selector

The element selector is used to style HTML elements such as `body` and `footer`.

### Class Selector

The class selector is used to style elements with classes such as `.course-card`, `.featured`, and `.contact-button`.

### ID Selector

The ID selector `#main-header` is used to style the main header of the webpage.

### Grouping Selector

The grouping selector `h1, h2, h3` is used to apply the same styling to multiple heading elements.

### Descendant Selector

The descendant selector `.course-card a` is used to style links that are inside the course cards.

### Pseudo-Class

The `:hover` pseudo-class is used on the Contact Us button and course links. The appearance changes when the mouse moves over the element.

## Design

The webpage includes:

* A styled page background
* A styled header
* Course cards
* A featured course with different styling
* Styled course links
* A Contact Us button
* A hover effect
* A styled footer
* Appropriate margin and padding

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html in a web browser.
5. Move the mouse over the Contact Us button or course links to see the hover effect.
